Descripción completa del proyecto

Un sitio web en donde los usuarios pueden gastar sus fichas para jugar distintos juegos de casino. Originalmente iba a tener varios juegos más pero con solo 2 juegos sirve para mostrar el funcionamiento correcto del proyecto. Se puede jugar a la maquina tragamonedas y al Blackjack.
  Los juegos son otras de las practicas en mi universidad. En los primeros años se nos pide hacer distintos juegos en Python para mezclar un lenguaje de programación que nunca vimos hasta ese momento con algo divertido. Los juegos que hice con mi grupo eran de casino por los que decidi volver a hacerlos pero en JavaScript y como si se pareciera más a un casino de verdad agregando un sistema de fichas con el cual el jugador puede elegir cuantas fichas apostar.
  En esta ocasión aproveche para estudiar como organizar mejor la estructura de los proyectos porque en el trabajo anterior el manejo de las rutas, la lógica del servidor y el CRUD de la base de datos se controló todo en el mismo archivo. En un proyecto chico puede no causar ningún problema, pero en proyectos más grandes complejiza en gran medida el desarrollo y mantenimiento.
  También aproveche para hacer un repaso de MongoDB, ya que solamente se dicta una materia de dicha base de datos.

Lo que aprendí

• Patrón MVC (modelo, vista, controlador) — Arquitectura que separa la lógica de datos, la interfaz y el control de flujo en una aplicación.
• MongoDB — Base de datos NoSQL orientada a documentos, ideal para manejar grandes volúmenes de datos flexibles.
• Nuevos módulos de diseño gráfico: Bootstrap Icons — Conjunto de íconos oficiales de Bootstrap para enriquecer el diseño de aplicaciones web.
