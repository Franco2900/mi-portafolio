Resumen

Sitio web en el que se pueden publicar juegos de mesa para su venta y compra. Los usuarios pueden escribir comentarios de los productos y valorarlos con estrellas.

Repositorio GitHub : Práctica 1

Tecnologías usadas

Back-end:
NodeJS con el framework Express
Base de datos:
SQL
Front-end:
Bootstrap y EJS

Descripción completa del proyecto

Siempre que hacía proyectos de práctica eran para crear pequeños fragmentos de código y así entender cómo funciona un concepto, una funcionalidad o un módulo. Los proyectos grandes que realizaba siempre eran para la universidad y en grupos. Por eso este es mi primer gran proyecto hecho enteramente por mí.
  Los sitios web de tiendas son de las primeras cosas que se practican, y como me gustan mucho los juegos de mesa, un día decidí hacer un sitio web como si fuera un vendedor de estos productos.
  A continuación daré una descripción completa de todas las funcionalidades disponibles en el sitio web. Para empezar, el sitio se divide en las siguientes secciones: Inicio (o Home, como prefieras llamarlo); Productos, que a su vez se divide en Compra y Venta; Contacto, con todos los medios de comunicación y Preguntas frecuentes; Iniciar sesión y Registrarse, para acceder a la cuenta; y finalmente Perfil, donde el usuario puede cambiar su nombre, su contraseña e imagen de perfil.
  Los visitantes no registrados solo pueden ver la sección de Compra para consultar los productos disponibles, pero no pueden interactuar hasta que inicien sesión. Los usuarios registrados con rol de usuario común pueden comprar productos, darles una puntuación de hasta 5 estrellas (el sistema modificará automáticamente la calificación general de cada producto cada vez que un usuario puntúe), comprar uno o varios productos a la vez, dejar comentarios y responder a los comentarios de otros usuarios. Los administradores tienen las mismas funciones que un usuario común, además de poder publicar nuevos artículos a la venta.

Lo que aprendí

• Enrutamiento — Proceso de definir las rutas de una aplicación web, indicando qué contenido o acción se ejecuta según la URL solicitada.
• Métodos GET y POST — Formas de enviar datos entre cliente y servidor: GET para obtener información y POST para enviar o modificar datos.
• EJS — Motor de plantillas que permite incrustar JavaScript en HTML para generar páginas dinámicas.
• Middleware — Funciones intermedias que procesan las solicitudes antes de llegar al controlador, útiles para validaciones, autenticación o manejo de errores.
• Conexión y trabajo con una base de datos — Integración de la aplicación con sistemas de almacenamiento de datos (como SQL o NoSQL) para guardar, consultar y actualizar información.
• Gestión de sesión de usuario — Mecanismo para mantener la información de un usuario mientras navega en la aplicación, como su estado de login o preferencias.
