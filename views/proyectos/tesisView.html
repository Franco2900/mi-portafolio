Resumen

Sitio web para cosechar, normalizar y actualizar la información de las revistas científicas argentinas en diferentes repositorios bibliográficos de forma automática, y para crear un listado unificado de toda la información recolectada.

Descripción completa del proyecto

Este es el proyecto que realicé como trabajo final para mi carrera de Licenciatura en Sistemas en la Universidad Nacional de Lanús. Su nombre, IARCA, significa Índice Automatizado de Revistas Científicas Argentinas.

Origen del problema
Gracias a las nuevas tecnologías de la informática, a partir de la década de 1990 se produjo un auge en la creación de revistas científicas. La digitalización facilitó la edición y distribución de estas publicaciones, al mismo tiempo que redujo significativamente los costos de producción y mantenimiento.

Cantidad de revistas científicas argentinas nuevas por década
Fuente: Políticas de promoción del conocimiento y derechos de propiedad intelectual - Centro Interdisciplinario de Estudios en Ciencia, Tecnología e Innovación (2023)

   Con nuevas tecnologías aparecen también nuevos desafíos. En el caso de las revistas científicas, el principal problema es la interoperabilidad entre sistemas debido a la falta de un estándar sobre qué metadatos utilizar. Cada repositorio bibliográfico solicita distintos metadatos y exige reglas diferentes.
   Esta problemática provoca que las revistas científicas argentinas estén dispersas en múltiples repositorios, cada uno con sus propios criterios. Como resultado, no es posible visualizar todas las publicaciones en un único lugar. Esto ocasiona problemas simples, como desconocer la cantidad total existente, y también dificultades más graves, como la imposibilidad de evaluar correctamente la calidad editorial.

Objetivo
El objetivo fue desarrollar un programa que recolecte y normalice los datos de las revistas científicas argentinas para mostrarlos en un único repositorio. Aunque ya existen trabajos de índole similar, como la base de datos Malena del CONICET, elaborada por expertos seleccionados, el proyecto IARCA se diferencia principalmente en que todo el proceso se realiza de forma automática, sin intervención humana.
   Para lograrlo, delimitamos qué campos cosechar, de qué bases de datos recolectar y aplicamos técnicas de web scraping y uso de API.

Funciones varias
Además de realizar la cosecha y normalización de la información, se brinda al usuario un medio para comprobar por sí mismo si los datos fueron recolectados correctamente. Para cada revista científica cosechada se ofrece, junto con sus datos, la URL del sitio de origen. Al hacer clic en la URL, el usuario accede directamente a la fuente.
   Dado que se reunieron datos de miles de revistas científicas, añadimos distintos filtros para que un usuario pueda buscar una revista en específico (por título, ISSN impreso, ISSN electrónico o institución).
   El usuario puede descargar todos los datos de un repositorio en específico o del listado final en formato .csv o .json. Se investigó la legalidad y ética del web scraping para determinar si era posible publicar los datos cosechados, y se concluyó que no existe inconveniente en que el usuario los descargue, ya que provienen de repositorios bibliográficos públicos y no generan perjuicio económico. (Fuente: Tutorial: Legality and Ethics of Web Scraping - Murray State University).
