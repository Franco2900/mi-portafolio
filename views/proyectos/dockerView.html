Descripción completa del proyecto

No importa qué tan buen programador uno pueda ser, si el usuario final no tiene las herramientas necesarias instaladas en su computadora para ver el programa desarrollado y así probarlo y evaluarlo, el trabajo realizado no se puede considerar como finalizado. Aquí es donde se usa Docker, que permite probar cualquier programa en cualquier computadora gracias a los contenedores.
   Los contenedores de Docker son, en esencia, máquinas virtuales en miniatura. Están encapsulados y aislados, pero además son más rápidas que las máquinas virtuales porque utilizan muchos menos recursos gracias a que los contenedores actúan como si fueran una aplicación más en la computadora.
   En esta ocasión hice una página web bastante simple con login y registro que funcionan gracias a una base de datos MySQL. Tanto el sitio web como MySQL tienen cada uno sus contenedores, y ambos contenedores están dentro de la misma red. El contenedor web tiene un puerto expuesto al host que permite al usuario probar el sitio desde cualquier navegador de su computadora. El contenedor SQL tiene un script .sql con el cual crea la base de datos, sus tablas y sus datos al iniciarse por primera vez.
   Para que los cambios que haga el usuario en la base de datos, como crear una cuenta nueva al registrarse, no se pierdan después de cerrar los contenedores y sean persistentes en el tiempo, el contenedor SQL utiliza un volumen.
   Por otro lado, existen dos versiones a usar con Docker: la versión para producción y la versión para desarrollo. Esta última versión está configurada para reiniciar el servidor ante cualquier cambio en el código (hot reload), así el desarrollador puede ver en vivo los cambios que hace al trabajar, mientras que la primera versión no tiene esto ya que está pensada para que la utilice un usuario final.

• Imágenes — Configuración y dependencias necesarias para que una aplicación se pueda ejecutar.
• Contenedores — Instancias en ejecución de una imagen.
• Puertos — Exposición del contenedor hacia el host.
• Redes — Conexiones virtuales que permiten la comunicación entre contenedores.
• Volúmenes — Espacios de almacenamiento persistente para conservar los datos fuera del ciclo de vida del contenedor.
• Docker Compose — Herramienta para definir y ejecutar aplicaciones multicontenedor mediante archivos YAML.
• Docker Compose Dev — Configuración especial para entornos de desarrollo.
• Hot Reload — Técnica que refleja cambios en el código automáticamente dentro del contenedor sin necesidad de reconstruir la imagen.
