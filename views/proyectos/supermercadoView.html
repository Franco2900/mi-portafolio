Resumen

Sistema web para supermercado online que integra la experiencia del cliente —con compras, historial, favoritos, filtros y comprobantes en PDF— junto con un panel de administración que permite gestionar productos, ofertas, roles de usuarios y reportes de ventas, ofreciendo una solución completa desde la compra hasta la gestión interna.

Descripción completa del proyecto

Sitio web para un supermercado online en el que los clientes pueden comprar productos y ofertas, ver versiones detalladas de los mismos y marcarlos como favoritos. Los productos marcados como favoritos aparecen siempre primero en la lista de productos a comprar para que el cliente los pueda comprar más rápido. Los productos y ofertas seleccionados son añadidos a un carrito donde el cliente puede quitar lo que no quiera o añadió por error y/o modificar la cantidad a comprar.

Lo comprado puede ser visto en el historial de compras el cuál tiene una herramienta para poder filtrar las compras por fecha (por defecto el historial de compras muestras las compras más nuevas a las más viejas). El historial también permite para cada compra hecha descargar un archivo pdf como comprobante el cuál indica que se compro, cuanto se compro, el costo y la fecha de compra.

Para cada acción que realiza el cliente se le envía notificaciones para que sepa que se confirmo/concluyo sus solicitudes.

Los administradores por su parte pueden hacer todas estas acciones, además de hacer el alta, baja y modificaciones de los productos y ofertas, cambiar el rol de los usuarios de cliente a admin o viceversa, y y acceder a reportes como ganancias de los productos más vendidos, ganancias por mes, cantidad de ventas, etc. Esto permite gestionar el supermercado de forma completa desde la misma plataforma.

En resumen, el proyecto integra tanto la parte de usuario como la de administrador, mostrando una aplicación web completa que cubre todo el flujo de un supermercado online: desde la compra hasta la gestión interna.

Lo que aprendí

• React — Aprendí a construir la aplicación usando vistas y componentes reutilizables, lo que hace que el sitio sea más ordenado y fácil de mantener.
• Contexto y estado — Incorporé variables de contexto y de estado para manejar información global como el usuario y el carrito, logrando que los cambios se reflejen en toda la aplicación sin necesidad de recargar.
• useEffect — Utilicé este hook para ejecutar acciones automáticas, como traer datos del backend o mantener la sesión del usuario activa si ya estaba logueado.
• Rutas protegidas — Implementé rutas que solo pueden ver los usuarios logueados y otras exclusivas para administradores, garantizando seguridad y control de acceso.
• Notificaciones — Integré toasts para dar feedback inmediato al usuario sobre sus acciones (ejemplo: modificar cantidades o confirmar compras).
• Integración completa — Conecté el frontend en React con el backend en Node.js y la base de datos en MySQL, logrando un sistema completo que cubre tanto la experiencia del cliente como la gestión del administrador.
• Diagramas de base de datos — Aprendí a diseñar diagramas completos de la base de datos utilizando draw.io, lo que me permitió visualizar y organizar mejor las relaciones entre tablas y entidades.
• Seeds de base de datos — Incorporé la práctica de crear seeds para vaciar la base de datos o rellenarla con datos de prueba, facilitando el desarrollo, las pruebas y la validación del sistema.
